# Graphite · 科技未来 · 0.6.0

2026-10-03：按用户要求，以克制的科技未来感替代青绿橙金主题。未使用 UI/UX 技能。

## 视觉方向

- 石墨黑 `#121316` 和中性深灰构成界面；银白 `#E5EAF1` 用于主要按钮，冰蓝 `#A6C8F2` 仅用于焦点、选择和少量状态强调。
- 背景使用低饱和银灰亮度带，不再混合青绿、橙红或金色；不透明度从 68% 收敛到 55%。GPU 与 CPU 静态回退调色一致。
- 彩色渐变按钮换成单色，面板边界使用低透明度白线；统计块减少外框，顶部流光降为 1 px、22% 不透明度，悬停扫光也降低亮度。
- 导航与品牌使用统一 24-unit 的单色矢量线条。桌面为冻结 DrawingImage，浏览器为同路径 SVG。用户自己的游戏封面不做处理，浏览器示例封面使用低饱和色。
- 设计参考 Apple HIG 关于克制用色、材质上保持可读性与内容层次的原则；这是 WPF/HTML 的独立实现，并非系统 Liquid Glass 或苹果原生组件。

参考：[Apple Color](https://developer.apple.com/design/human-interface-guidelines/color)、[Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)。

## 流体交互

保留 0.5.0 的 64×40 速度/位移场、60 Hz 固定步长、半拉格朗日平流与压力投影。鼠标沿线段注入动量，停止后继续搬运并衰减，不替换固定波纹。绘制跟随显示刷新，后台、隐藏、最小化或减少动画时停止。此次修改限于视觉呈现，未改动已验证的流场算法。

位移分量仍使用 128×40 不透明纹理、双 16 位编码，避免预乘透明度破坏数据。WPF 不支持硬件 Shader 时显示静态同色图；浏览器 context 丢失时显示同色 CSS 回退。WPF 测试截图使用相同公式的 CPU 位图，不作为 GPU 帧率证明。
