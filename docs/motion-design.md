## 使用的官方技能

用户提供的 `greensock/gsap` 是 JavaScript 动画库。通过官方文档找到独立的 [greensock/gsap-skills](https://github.com/greensock/gsap-skills)，使用 Codex 的 skill-installer 安装了本任务需要的三个官方技能：

- `gsap-core`：透明度、变换、缓动、覆盖冲突动画、减少动画偏好。
- `gsap-timeline`：用时间线组织多个元素的进入顺序。
- `gsap-performance`：避免逐帧修改布局，限制动画范围，及时清理。

安装路径为 `C:\Users\10367\.codex\skills\<技能名>`。本轮已直接读取并应用这些规范；技能目录将在下一轮对话中可用。没有安装与当前桌面工具无关的滚动、React 或框架技能。

## 视觉节奏

延续炭黑、暖白、青绿色的游戏库风格，动效只强化操作反馈和信息出现的顺序。主操作不等待动画完成，不改变命中区域。

| 场景 | 视觉变化 | 时长 / 延迟 |
| --- | --- | --- |
| 普通按钮按下 | 模板表面缩至 98.5%，释放回到 100% | 85 / 140 ms |
| 图标按钮按下 | 缩至 90%，让收藏和关闭反馈更明确 | 85 / 140 ms |
| 大封面悬停 | 在固定裁切框内放大至 102.5% | 160 ms，离开 180 ms |
| 页面 / 封面列表切换 | 透明度 72% → 100%，向上归位 6 DIP | 140–160 ms |
| 窗口进入 | 标题先进入，搜索工具栏稍后进入 | 160 ms，工具栏延迟 25 ms |
| 宽窗口详情 | 面板从右侧 14 DIP 归位，封面淡入，正文轻移入 | 180 ms；正文延迟 30 ms、持续 150 ms |
| 编辑 / 设置 | 内容向上归位 8 DIP 并淡入 | 180 ms |
| 封面加载 / 状态消息 | 透明度 65% → 100% | 140 ms |

采用 GSAP `power2.out` 对应的三次缓出曲线；WPF 使用 `CubicEase / EaseOut`。关闭详情立即完成逻辑操作和布局收起，快速打开另一个游戏可覆盖当前进入动画。

## 桌面实现

`src/CXLauncher/Views/Motion.cs` 用 WPF 的 `DoubleAnimation` 和渲染变换落实设计。桌面应用无需 JavaScript 或 WebView；GSAP 本身只用于浏览器预览。

- 只逐帧更新 `Opacity`、`ScaleTransform`、`TranslateTransform`。详情栏宽度仅在打开或关闭时更新一次。
- 新动画从当前渲染值继续，使用 `SnapshotAndReplace` 替换同一属性上的旧时钟。
- 结束时移除时钟；隐藏、卸载、最小化或关闭窗口时取消动画。没有永久循环、定时刷新或持续背景动画。
- Window 读取 `SystemParameters.ClientAreaAnimation` 和 `HighContrast`，并监听系统偏好变更。动画关闭时立即归位，保留正常焦点和操作。
- 按钮动画只变换模板表面，保留按钮布局与命中框，也保留模板中的禁用透明度。
- 不为整库条目创建进入时间线；保留已有虚拟化与封面引用释放机制。

## GSAP 交互预览

`design/motion-preview/index.html` 是可离线打开的独立预览，使用官方 **GSAP 3.15.0**。封面图形由 CSS 绘制，游戏名和路径均为示例。

支持悬停、按下、收藏、详情切换、导航、搜索、封面/列表切换，以及重新播放、单次自动演示、慢放与减少动画。使用 GSAP Timeline、`overwrite`、`matchMedia`，遵循系统 `prefers-reduced-motion`；重设、页面隐藏和退出时清理动画。

预览不会修改真实游戏库，不执行任何程序。保留 GSAP 原始版权头和官方 Standard License 链接。
