## CX Launcher 0.6.0 · Graphite

Windows 本地游戏启动器，支持手动添加 EXE / 快捷方式，在统一游戏库中整理、搜索和启动。

### 本版亮点

- Graphite 石墨黑与银白主题，少量冰蓝强调、单色线性图标、轻量玻璃面板。
- 银灰流体背景响应鼠标拖动，保留余流与自然衰减；后台、最小化和减少动画时暂停。
- 封面网格与列表、分类、收藏、最近启动、名称搜索。
- 游戏编辑、启动参数、工作目录、本地封面，失效路径反馈。
- 本地 JSON 原子保存、备份恢复、导入预览与合并、导出、单实例。

### 下载

| 附件 | 说明 |
| --- | --- |
| `CXLauncher-0.6.0-win-x64-self-contained.zip` | 推荐，自带运行时，完整解压后运行 `CXLauncher.exe` |
| `CXLauncher-0.6.0-win-x64-framework-dependent.zip` | 精简版，需要 .NET 10 Desktop Runtime x64 |
| `*.zip.sha256` | 对应 ZIP 的 SHA-256 校验文件 |

免安装，默认数据保存在 `%LOCALAPPDATA%\CXLauncher`。不包含游戏；删除库记录不会删除游戏文件。
