# CX Launcher 0.6.0 实施与验证记录

更新日期：2026-10-03（Asia/Hong_Kong）。状态：0.6.0 Graphite 主题完成，石墨银灰流体、少量冰蓝强调、轻量面板边界与单色矢量图标替代彩色主题。104 项桌面检查、浏览器交互和两种 ZIP 解压启动验证通过。完整跨设备性能与兼容性验收尚未完成。详见 [流体设计记录](../design/liquid-spectrum/README.md)。

## 交付

工程为一个 WPF 应用和一个自动测试项目，解决方案为 `CXLauncher.slnx`。采用 .NET 10、WPF、自定义资源主题与 CommunityToolkit.Mvvm 8.4.0。项目 SDK 10.0.401、运行时 10.0.12；Release 编译为 0 警告、0 错误。

| 分发版本 | ZIP 体积 | 解压体积 | 运行依赖 |
| --- | ---: | ---: | --- |
| 框架依赖 win-x64 | 约 0.67 MiB | 约 0.92 MiB | .NET 10 Desktop Runtime x64 |
| 自包含 win-x64 | 约 62.72 MiB | 约 140.31 MiB | 已携带运行时，可离线运行 |

交付 ZIP、说明与 SHA-256 文件位于 `dist/`；现成运行目录位于 `.artifacts/publish/`。框架依赖版附带依赖检查启动脚本；自包含版可直接运行 `CXLauncher.exe`。本版提供便携 ZIP，尚未制作安装器或签名发布。

两种最终 ZIP 均已校验 SHA-256 并实际解压执行：正常启动、第二实例正常退出、主窗口正常关闭并写入窗口设置。测试使用隔离数据目录；框架依赖版通过项目内 Desktop Runtime 运行，自包含版清除 DOTNET_ROOT 环境变量后运行。记录位于 `dist/verification.json`；验证脚本为 `packaging/verify-packages.ps1`。

## 实施范围

- 完成添加 → 编辑 → 保存 → 重新读取 → 启动的流程，手动选择和拖入均不自动执行游戏。
- `.exe` 路径、参数、工作目录分别传入 `ProcessStartInfo`，不拼接 Shell 命令；`.lnk` 使用 Windows Shell，拒绝外部参数覆盖。
- 收藏、分类、搜索、名称/最近启动/最近添加排序、封面/列表切换；宽窗口详情栏与窄窗口详情对话框。
- 0.1.1：基于三个官方 GSAP 技能实施 WPF 原生动效，增加真实 GSAP 3.15.0 离线预览。时长、清理、系统偏好与验证见 [动效记录](motion-design.md)。
- 0.2.0：深空蓝 / 冰蓝 / 紫色主题、生成品牌和导航图标、标题面板与静态网格；图标编译为资源，PNG 与 ICO 包含在软件中。生成提示词、路径与对比度验证见 [科技主题记录](../design/tech-theme/README.md)。
- 0.3.0：按用户指定参考项目重构为石墨灰玻璃界面、淡紫与暖色点缀；192 DIP 侧栏、数量概览、集中工具栏、内嵌缩略图卡片。卡片 240 ms 浮起、700 ms 单次扫光，页头唯一 3.8 秒流光；后台暂停、减少动画即时清理、容器回收和关闭释放。本轮未使用 UI/UX Pro Max。
- 历史 0.5.0：青碧、橙金配色与持续二维流场；60 Hz 固定步长模拟，绘制跟随显示刷新。快速划动沿线段注入动量，停止后速度和位移分别衰减。详见流体设计记录。
- 历史 0.4.0：整个主窗口使用 `#24202B` 底色、32% 不透明度的低饱和流体，按钮与边缘改为灰粉米金。独立 HLSL Shader / WebGL 实现五层坐标扭曲，鼠标速度推动附近色带，四个涟漪在约 2.5 秒内消散。硬件渲染、不支持时静态回退；前台限频 30 FPS，后台/隐藏/减少动画停钟。继续遵守不使用 UI/UX Pro Max 的要求。
- 图片复制至应用数据目录；缩略图按尺寸解码，后台并发最多 2 个，内存缓存最多 64 张。屏外容器释放图片引用和取消待处理任务。单张文件限制 30 MiB，最大 1 亿像素，并按宽/高分别限制解码尺寸。
- 网格按自适应列数分行，由 `VirtualizingStackPanel` 回收行容器；列表直接虚拟化。
- 两类配置串行写入，同目录临时文件、刷盘、原子替换，分别保留最近 5 个有效备份。缺少必需结构、损坏 JSON 或不支持版本不会覆盖成默认空库。
- 恢复时用户确认，原文件保留为 `.preserved-*`；没有备份时提供保留原文件后新建入口。设置损坏时使用临时默认值，并暂停写入该文件。
- JSON 导入校验、预览计数、按路径合并、冲突标识重分配；导出保留完整条目元数据。JSON 不携带图片，完整迁移请复制数据目录。
- 单实例按用户与数据目录区分，通过当前用户可用的命名管道激活已有窗口。
- 日志不记录完整启动参数或异常中的用户路径；单个日志达到 256 KiB 后轮换，最多保留当前和 3 个历史文件。

## 自动验证

运行 `scripts/build.ps1 -UiSmoke`。测试项目是独立可执行验证程序，无额外测试框架依赖；失败返回非零退出码。最终通过 **104 项检查**，覆盖：

1. JSON 字段往返、并发保存、备份上限、结构/版本校验、损坏文件保护和恢复。
2. 导入重复路径、标识冲突、导出再读、封面标识越界拒绝。
3. 使用实际子进程捕获中文/空格路径、带引号参数、`&()$;` 字面值、工作目录；真实 `.lnk` 的嵌入参数和工作目录。提交后子进程仍运行，重复请求受到抑制。
4. 添加、编辑、重启读取、收藏、分类、最近启动、中文搜索、保存失败后的状态一致性；移除已有条目保留实际文件。
5. 图片副本与缩略图、取消任务、64 张缓存上限，以及编辑封面后可见容器重新加载。
6. 空库、1,000 条游戏、搜索无结果、860×560 窗口、详情栏、窄窗口详情对话框、编辑和设置窗口的 WPF 截图；Ctrl+F 焦点命令和详情关闭命令。
7. 动画中断与覆盖、减少动画即时归位、隐藏/最小化清理、按钮释放与禁用状态、快速详情切换后关闭、对话框时钟清理。
8. 四枚生成图标的资源加载、冻结与按 96/160 像素解码的尺寸上限。
9. 卡片浮起只改变渲染位置、单次扫光结束清理、前台光带数量限制、减少动画/隐藏/最小化/后台暂停、卡片集合回收和窗口关闭释放玻璃动画。
10. 嵌入 PS3 字节码、连续色场与低饱和非紫色配色、GPU/静态分支、时间推进、同时间下鼠标扭曲场景、流场持续搬运、快速搅动稳定性和停止后收敛、减少动画禁用扰动、后台停钟、位图截图与恢复。

0.3.0 的 1,000 条库实测封面只生成 **3 / 250 行容器**，滚动后仍为 3 行；列表生成 **6 / 1,000 条目容器**。容器数量随布局与视口变化，此检查不能单独证明全部滚动性能或多 DPI 表现。

0.6.0 对比度：主文字/底色 17.21:1，次文字/面板最低 7.03:1，保守按旧版更亮扫光检查时次文字最低 5.24:1，主按钮文字 14.41:1，控件边界/表面 3.58:1。浏览器低饱和取样、指针交互、后台暂停、减少动画、紧凑布局与 context 丢失回退均通过。

截图和测试隔离数据位于 `.artifacts/tests/<运行标识>/`。程序默认没有演示游戏；测试生成的条目不会写入真实用户游戏库。

## 初步性能测量

以下为 0.1.0 的基线，0.6.0 本轮未完整复测。动画清理与容器数量检查不代替完整性能验收。

机器：Windows 11 build 26300 x64、AMD Ryzen 9 5900X（24 逻辑处理器）、63.9 GiB 内存。机器具有 ZHITAI TiPlus9100 2TB 等磁盘；此轮没有单独确认 C: 分区对应的物理磁盘，不能宣称满足既定 SSD 基准的全部条件。

数据为 500 个模拟条目、500 个独立本地封面及预生成缩略图。目标文件只是存在性检查用的无效 EXE 占位文件，测量时不会执行。使用自包含 Release 构建，无调试器。

| 项目 | 本轮结果 | 计划目标/状态 |
| --- | --- | --- |
| 热启动 10 次 | 中位数 1,092.2 ms，最大 1,105.2 ms | ≤ 800 ms；尚未达到 |
| 首次测量运行 | 1,107.1 ms | 未在系统重启后测量，不能称为冷启动 |
| 空闲私有工作集 | 133.6 MiB，首页稳定 30 秒时 | 争取 ≤ 120 MB；尚未达到 |
| 专用字节 | 249.8 MiB（60 秒采样结束时） | 记录项，和私有工作集不同 |
| 总工作集 | 318.5 MiB（60 秒采样结束时） | 记录项，含共享页 |
| 空闲 CPU | 0.7258%，稳定后采样 60 秒，按 24 逻辑处理器归一化 | < 0.5%；本轮尚未达到 |
| 第二个实例 | 正常退出，首个实例继续运行 | 通过 |

热启动核对采用操作系统进程 StartTime 到应用的 UTC Ready 日志时间。Ready 在元数据加载且窗口进入 ApplicationIdle 后写入，不表示全部封面解码结束。第一轮外部 PowerShell/轮询口径的热启动中位数为 1,074.7 ms；核对轮为 1,092.2 ms，测量波动和轮询开销未被混同为优化结果。

内存和 CPU 数值来自原始 60 秒基线；启动核对轮只额外采样 1 秒 CPU，其 0% 结果**不作为**空闲 CPU 验收证据。原始记录分别为 `.artifacts/performance/92fa35d606bf46f287455a0a3fd34aa5/performance-baseline.json` 与 `startup-audit.json`。

可用 `scripts/create-performance-library.py` 生成隔离数据，再以 `scripts/measure-performance.ps1 -DataDirectory <目录>` 复测。脚本强制测试目录位于 `.artifacts`，默认记录 1 次初始运行、10 次热启动和 60 秒 CPU。性能计数器查询可能需要当前运行环境授权。
