CX Launcher 0.4.0 / Windows x64 / 流彩熔境

双击 CXLauncher.exe 启动。
框架依赖版需要 .NET 10 Desktop Runtime x64，可运行“启动 CX Launcher.cmd”检查。
自包含版已携带运行时，解压后可以离线启动。
请先完整解压 ZIP，保留同目录下的文件，再运行 CXLauncher.exe。

暖灰底色上的 32% 透明度低饱和流彩、灰粉和米金色按钮、透明玻璃卡片。
鼠标移动会搅动附近色带，涟漪在约 2.5 秒内消散。
卡片悬停浮起并扫光，顶部光带缓缓流动。四枚生成图标已嵌入程序。
支持 Pixel Shader 3.0 的显卡使用实时背景；软件渲染或不支持的显卡使用静态同色背景。
进入后台或最小化时暂停装饰动画，关闭 Windows 动画时也会关闭鼠标扰动。

默认数据目录：%LOCALAPPDATA%\CXLauncher
移除条目只修改游戏库，游戏文件会保留。
JSON 导出包含条目但不包含图片。完整迁移请备份整个数据目录。

本版已在当前 Windows 11 开发机验证。Windows 10 22H2 与多 DPI 实机验收仍待完成。
